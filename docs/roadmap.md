# Roadmap

## 0.1.x

- 初期 9 Skills の文面改善
- use-cases の追加
- harness case の拡充
- メタデータ検証の改善

具体的な改善 Issue の下書きは `.github/ISSUE_EXAMPLES/` にあります。初期公開後は、この下書きをもとに優先度を付けて Issue 化します。

## 将来検討

- plugin 化
- より本格的な eval harness
- `codex exec --json` による自動評価
- サンプル Excel / Word テンプレートの追加
- ChatGPT Skills 向けパッケージ化
- 多言語対応
- 部門別 use-case 拡充
- ローカル LLM 対応
- Web UI
- PDF / CSV アップロード
- Markdown / PDF 出力

## 初期版に入れないもの

ローカル LLM、Web UI、Docker、API 連携、電子カルテ連携、患者情報を扱う処理は初期版には入れません。必要性が出た場合も、安全性、個人情報保護、院内規程、運用責任を確認してから検討します。
