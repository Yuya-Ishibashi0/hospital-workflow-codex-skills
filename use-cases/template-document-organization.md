# 既存様式に情報を整理する

## 業務名

研修報告書や委員会報告書など、既存様式への情報整理

## よくある困りごと

- メモ、議事録、アンケート結果が散らばっている
- 既存 Excel / Word 様式のどこに何を入れるか迷う
- 不足情報と空欄の扱いが曖昧になる
- 提出前の確認ポイントが属人的になっている

## 推奨 Skill

`hospital-template-document-builder`

## 補助 Skill

- `hospital-document-drafter`
- `survey-insight-analyst`
- `meeting-action-organizer`

## 入力例

```text
研修後アンケートの集計メモと、既存の研修報告書様式の項目があります。
様式に沿って、どの情報をどこに入れるか整理してください。
不足情報は補完せず、不足として残してください。
```

## 出力例

- 項目対応表
- 抽出情報
- 不足情報
- 空欄として残す項目
- 転記ルール
- 人間確認ポイント

## 注意点

- 不明な情報を勝手に補完しない
- 様式にない項目を勝手に追加しない
- 元資料と様式の対応関係を残す

## 対象外

- 患者情報を含む資料
- 診療記録
- 申し送り文
- 患者説明文
