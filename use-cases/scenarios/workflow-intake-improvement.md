# 職員への依頼がメール・紙・口頭に分散している状態を整理する

## 想定する場面

総務への依頼、研修申込、物品購入申請などが、メール、紙、内線、口頭で届き、受付漏れや確認の重複が起きている場面です。

## 最初の依頼

```text
総務への依頼がメール、紙、口頭に分かれていて管理しづらいです。
現在の受付方法を整理し、現場の負担を増やさない改善案を作りたいです。
必要な情報をヒアリングしてください。
```

## Codexが確認すること

- どのような依頼があるか
- 誰が、どの手段で依頼するか
- 受付後に誰が何をするか
- 件数、頻度、締切
- 現在使っている台帳や様式
- 例外対応と承認経路
- 変えられない院内ルール

## 資料がある場合

受付台帳、依頼書、メール文面、業務メモを、個人情報を除いて渡します。資料がなければCodexがヒアリングシートを作り、担当者への聞き取りから現状を整理します。

## 作成されるファイル

- 現在の受付から完了までの業務フロー `.docx`
- 困りごとが発生する場所と原因
- 受付方法を整理する改善提案書 `.docx`
- 小さく試すための実施チェックリスト `.xlsx`

## 人が確認する点

- 現場の手間が別の担当者へ移るだけになっていないか
- 例外依頼や緊急時の経路が残っているか
- 個人情報、権限、院内規程に問題がないか
