# メモや集計結果を既存の院内様式へ整理する

## 想定する場面

研修報告書、委員会報告書、月次報告書など、提出先が指定したExcel・Word・PowerPoint様式へ情報を整理する場面です。

## 最初の依頼

```text
研修報告書を指定のExcel様式で作りたいです。
元資料と空の様式を確認し、足りない資料があれば先に教えてください。
不明な項目は推測せず空欄にしてください。
```

## Codexへ渡す資料

1. 入力先となる空のExcel、Word、PowerPoint
2. 元になるメモ、集計表、議事録、アンケート結果
3. 記入例や提出ルールがあれば、その資料

ファイル名だけで判断させず、「このExcelが提出用様式です」「このメモが元資料です」と役割を伝えます。

## 資料が足りない場合

Codexは様式の項目と元資料を照合し、次のように分けます。

- 元資料から記入できる項目
- 判断が必要な項目
- 情報がなく空欄にする項目
- 担当者へ確認する項目

必要に応じて、不足情報を集めるための確認票も作成します。

## 作成されるファイル

- 情報を整理したExcel、Word、PowerPoint
- 元資料と入力先の項目対応表
- 空欄・不足情報・確認事項一覧

## 人が確認する点

- 元資料の意味を変えずに転記されているか
- 様式にない情報が勝手に追加されていないか
- 数字、日付、部署名、提出先が正しいか
- 数式、印刷範囲、ページ崩れがないか
