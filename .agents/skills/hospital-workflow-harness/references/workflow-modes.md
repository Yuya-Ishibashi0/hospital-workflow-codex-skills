# Workflow Modes

Codex は、依頼内容に応じて作業モードを切り替えます。

## Discovery mode

目的: 現状把握と不足情報の整理。

使う場面:

- 業務の全体像が曖昧
- 関係者や入力帳票が不明
- まずヒアリング項目を作りたい

出力:

- 確認質問
- 現状仮説
- 不足情報
- ヒアリングシート

## Structuring mode

目的: 情報を業務フロー、論点、要件に整理する。

使う場面:

- 会議メモがある
- 業務手順メモがある
- 帳票や作業一覧を整理したい

出力:

- 業務フロー
- 課題一覧
- 例外処理
- 確認事項

## Proposal mode

目的: 改善案や提案書のたたき台を作る。

使う場面:

- 上司や関係部署へ相談したい
- 二重入力や転記作業を減らしたい
- 小さく試す改善案を作りたい

出力:

- 改善案
- メリット、リスク
- 小さく試す案
- 相談文

## Implementation-planning mode

目的: 実装前の作業分解、運用設計、確認事項を作る。

使う場面:

- 業務変更前の確認事項を整理したい
- 運用手順を固めたい
- 関係部署に確認する項目を作りたい

出力:

- 作業分解
- 確認事項一覧
- 運用設計
- 関係部署への確認事項

## Review mode

目的: 既存成果物の抜け漏れ、安全境界、現場定着性を確認する。

使う場面:

- 提案書やマニュアルを見直したい
- 患者情報や診療判断に近づいていないか確認したい
- 現場運用に無理がないか見たい

出力:

- 指摘事項
- 修正案
- 人間確認ポイント
