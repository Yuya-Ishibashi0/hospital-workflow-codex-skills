# 研修アンケートを分析する

## 業務名

研修アンケート、職員アンケート、勉強会アンケートの整理

## よくある困りごと

- 自由記述の分類に時間がかかる
- ポジティブな意見と改善要望が混在している
- 次回研修への示唆を報告書にまとめにくい
- 個人が特定されない表現に整える必要がある

## 推奨 Skill

`survey-insight-analyst`

## 補助 Skill

- `hospital-document-drafter`
- `training-program-designer`
- `hospital-template-document-builder`

## 入力例

```text
AIリテラシー研修のアンケート自由記述を、良かった点、改善要望、次回テーマ案に分類してください。
個人が特定される表現は避け、報告書に使いやすい形にしてください。
```

## 出力例

- 全体傾向
- 自由記述の分類
- ポジティブな意見
- 改善要望
- 次回研修への示唆
- 報告書ドラフト

## 注意点

- 個人が特定される記述は使わない
- 少数意見を全体傾向として断定しない
- 院内共有前に人間が確認する

## 対象外

- 患者アンケート
- 医療判断や診療内容に関する分析
- 個人情報を含む自由記述
