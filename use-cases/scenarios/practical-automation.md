# 費用をかけず、今の業務に無理なく取り入れられる改善・自動化を考える

## 想定する場面

新しいシステムを導入する前に、現在使っているExcel、Forms、共有フォルダ、メールなどを活用し、現場の運用を大きく変えずに手作業を減らしたい場面です。

## 最初の依頼

```text
毎月の研修参加者一覧を手作業でまとめています。
現在の業務フローを確認したうえで、追加費用を抑え、職員が無理なく使える改善方法を考えてください。
まず必要な資料と確認事項を教えてください。
```

## Codexが確認すること

- 現在の作業手順と担当者
- 入力元と完成物
- 使用中のExcel、Forms、共有フォルダなど
- 件数、頻度、所要時間
- 手作業が必要な理由
- 例外、承認、確認作業
- 利用できる院内環境と変更できないルール

資料がない場合は、Codexが現状確認用のヒアリングシートを作成します。いきなり自動化案を出さず、現在の業務と困りごとを先に整理します。

## 検討する順番

1. 不要な作業や重複をなくせないか
2. 入力方法やファイルの置き場所を統一できないか
3. 既存のExcel関数やフォームで軽減できないか
4. 小さな範囲で試せるか
5. システム担当者への相談が必要か

## 作成されるファイル

- 現状業務フローと負担の整理 `.docx`
- 費用、現場負担、効果、リスクの比較表 `.xlsx`
- 追加費用を抑えた改善案 `.docx`
- 小さく試すための実施計画

## 人が確認する点

- 実際の院内環境で利用できるか
- 特定の職員だけに負担が集中しないか
- 保守できる担当者がいるか
- 情報システム、個人情報、院内規程の確認が必要か
