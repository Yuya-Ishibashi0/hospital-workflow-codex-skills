# Artifact Generation

この文書は、Codex が成果物を「実際に開いて編集できるファイル」として生成するための実行ルールです。

## 形式ごとの生成方法

| 成果物 | 優先形式 | 使用する機能 |
| --- | --- | --- |
| マニュアル、報告書、依頼文、議事録 | `.docx` | Documents / document generation capability |
| 集計表、チェックリスト、対応表 | `.xlsx` | Spreadsheets / workbook generation capability |
| 研修資料、掲示物、スライド | `.pptx` | Presentations / slide generation capability |
| 軽量な補助資料 | `.md`, `.csv` | 通常のファイル編集 |

利用可能な Skill やツールを確認し、文書には文書生成機能、表には表計算機能、スライドにはプレゼンテーション生成機能を使います。

## 禁止事項

- Markdown やプレーンテキストを `.docx` に名前変更しない。
- CSV を `.xlsx` に名前変更しない。
- Markdown を `.pptx` に名前変更しない。
- ファイルを作成せず、チャットに成果物全文を返して完了扱いにしない。
- 開けるか確認していないファイルを完成扱いにしない。

## 作成手順

1. `artifact-output-policy.md` から標準形式を決める。
2. 入力された既存様式がある場合は、元ファイルを保護して複製する。
3. 対応する文書・表計算・プレゼンテーション機能で生成する。
4. `outputs/YYYYMMDD-task-name/` に保存する。
5. `python3 tools/validate_artifacts.py <task-directory>` でファイル構造を確認する。
6. 可能な場合はレンダリングまたはアプリで開き、文字切れ、表崩れ、空白ページ、スライド重なりを確認する。
7. `run.json` に成果物を記録し、状態を `review_pending` にする。

## 最低限の品質確認

### DOCX

- Word 文書として開ける。
- 見出し階層が一貫している。
- 表がページ幅を超えていない。
- チェックリストや改訂履歴が必要に応じて含まれる。

### XLSX

- Excel ブックとして開ける。
- 見出し行、列幅、折り返し、入力欄が分かる。
- 数式が必要な場合は式として入力されている。
- 不明情報を推測値で埋めていない。

### PPTX

- PowerPoint として開ける。
- タイトル、本文、図表がスライド外にはみ出していない。
- 文字量が過剰でない。
- 発表順序と目的が一貫している。

## フォールバック

必要な生成機能が利用できない場合は、偽の Office ファイルを作りません。

1. 編集可能な `.md` または `.csv` を作成する。
2. 本来作る予定だった形式を `run.json` とチャット返信に記録する。
3. Office ファイル化が未実施であることを明示する。

フォールバック成果物を、完成した `.docx` / `.xlsx` / `.pptx` として報告してはいけません。
